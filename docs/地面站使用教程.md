# 地面站使用教程

本文 192.0.2.0/24 地址仅用于文档示例；请替换为现场 HM30 有线网卡地址后执行。

## 准备与启动

地面正常入口为修改后的MissionPlanner，不需要同时运行独立receiver。当前源码在MIssion-Planner-NPU/MissionPlanner/Plugins/MpNanoImages，具体运行EXE由MP开发对话提供。升级插件前退出目标MP，保留其接收目录、日志和游标；不要往运行中的进程覆盖DLL。

1. 接好HM30地面端LAN与电脑网口，设置正确有线地址，例如192.0.2.30/24。
2. 启动MP，图片回传窗口自动打开，也可从顶部“图片回传”按钮打开。
3. 监听地址使用电脑HM30网口IP，端口8765；127.0.0.1只能本机访问。
4. 选择容量足够的接收目录，点击开始接收。任务和接收目录不能由第二个接收实例同时占用。
5. 天空发送端应指向相同地址/端口，防火墙限定来源、程序和网口放行。Type-C飞控连接不替代图片LAN。

## 观看

当前已实测版本四格横向、每次更新一格，图片右下角显示原文件名；默认1秒，可调0.2～10秒。四格全部更新需要约4个间隔。暂停轮换或隐藏窗口不会停止接收，恢复可继续观看。

此前版本用任务下拉框，手动选择会关闭自动跟随；需要查看当前任务时恢复跟随。另一个对话正在实现“当前任务自动显示＋独立历史回看”，本仓库不宣称该交互已交付。使用教程后续应以MP实际发布版更新，不把设计方案当作现有功能。

重新打开窗口不等于删除历史图片或重置任务。显式从头回放会产生重复显示日志，但不是重复传输。断开连接也不表示任务已结束，可能仍有天空或地面积压。

## 计数与目录

天空待传是最近上报的已发现/已准备数量，不包含尚未扫描的原图；地面待显示是当前所选任务的接收记录估计，可能短暂滞后。ACK表示落盘，不表示已看完。

接收目录由窗口选择，应选择具有写入权限且空间充足的数据目录。以receiver_start日志为准。通常配置/日志/游标在%LOCALAPPDATA%/MpNano/P3，接收图片也可以在别处。

## 排障

- 无连接：查监听IP、LAN状态、Jetson路由和限定防火墙，不只查SSH。
- 接收增长但看不到图：查当前任务、暂停、窗口是否隐藏、显示游标和display_skipped日志。
- 天空重连但失败次数为0：这是网络恢复，不能当坏图已经跳过。
- STORAGE_ERROR：查地面容量/权限；不要清空天空状态掩盖问题。
- 队首显示等待增长：观看慢于接收，调节观看节奏或稍后回看，当前不自动跳最新图。

历史数据清理应针对确认已结束且无待传/待显示的任务；地面记录还承担去重职责。临时防火墙规则测试结束按授权清理，不默认永久开放。接收服务重启与MP整机重启是不同验收项目。
